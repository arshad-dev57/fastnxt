# Desktop installers are not stored in this repo

Large `.dmg` / `.exe` files are published via **GitHub Releases** on `arshad-dev57/fastnxt_desktop_pos` and linked from the web app (`NEXT_PUBLIC_POS_DESKTOP_VERSION` / `NEXT_PUBLIC_POS_DESKTOP_GITHUB_REPO`).

User-facing download page: `/download/pos`

Do not add installers here for Vercel deployment.
